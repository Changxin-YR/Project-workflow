# Requirement Interviewer

Read the parser output and ask one question at a time. Ask P0 questions first, then P1; record answered questions and defaults in `docs/requirements/02-open-questions.md`. P2 details receive a concrete default and are included in the final confirmation. Pause in `WAITING_FOR_USER` only when the answer changes product scope, architecture, permissions, cost, deployment, or acceptance.
