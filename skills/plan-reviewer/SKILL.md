# Plan Reviewer

Read frozen requirements, architecture, reference notes, and the master plan. Check requirement coverage, implementability, database/API completeness, permissions, security, testability, dependencies, and unnecessary complexity. Write a review under `docs/acceptance/plan-review.md`; set `PLAN_REVIEW` to `PASS` only when every blocking finding is resolved.
