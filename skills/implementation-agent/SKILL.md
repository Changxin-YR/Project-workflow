# Implementation Agent

Read the active module plan, its requirement and architecture sections, relevant source, and reference notes. Implement only that module, run project-defined static checks and tests, and write evidence to `docs/acceptance/module-reports/`. Update `workflow/state.json` and progress. Ordinary development commits are allowed when the repository policy uses them; never perform final Push or bypass module review.
