# GitHub Reference Miner

Derive search terms from the frozen requirements. Use public repositories only. Save search evidence to `docs/research/github-search.md` and a scored candidate table to `docs/research/reference-matrix.md`, weighting requirements similarity, stack, architecture, quality, activity, and license. Keep 3-5 high-value candidates. If a checkout is needed, place it under `references/repos/`, mark it untrusted, and never execute its scripts, installers, hooks, or credentials.
